# 来源与核验规则

## 允许的来源

1. 官方页面：景区/博物馆/餐厅官网、官方公众号文章、12306/航司官方页面。
2. 地图平台：高德地图 POI 页面（用于地址、坐标、营业时间线索）。
3. 公开口碑：大众点评、小红书公开笔记、抖音公开视频（只引用链接与结论摘要）。
4. 已核实内容：人工确认过的信息（用户提供或现场核对）。

## 禁止

- 抓取小红书/抖音评论区数据、绕过登录或反爬。
- 把平台评分当作唯一事实来源；评分只作为线索。
- 编造营业时间、价格、评分、预约要求、车次、航班号。
- 在没有来源的情况下写“人均 ¥XX”“每天 09:00-22:00”。

## 核验标记

- 已人工确认过的信息：`verify: false`。
- 来自模型推测或平台线索、可能变化：`verify: true`，页面显示「待核验」。
- 完全无法确认：留空，并在 `sources[]` 里记一条 `status: "unverified"`。

## 引用格式

```json
{ "place_id": "sy-gugong", "url": "https://example.com", "title": "沈阳故宫官方开放时间", "retrieved_at": "2026-09-10", "status": "verified" }
```
