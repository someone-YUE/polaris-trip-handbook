# v1 之后的升级路径

v1 只做本机单文件 HTML。以下能力按需再加，不要提前实现。

## 1. 内嵌高德地图

- 申请高德开放平台「Web 端（JS API）」Key，白名单先填 `localhost`。
- 在 `config.json` 的 `map.amap_web_js_key` 填入 Key。
- 页面模板增加地图容器，用 `places[].longitude/latitude` 打点；保持「免 Key 时自动降级为跳转链接」。
- 本地预览必须走 `scripts/serve.py`（localhost），不要用 file:// 打开。

## 2. 云端分享

- 目标：同行打开同一个 URL，看到的永远是同一份攻略。
- 方案：静态托管（腾讯云 CloudBase / 对象存储 + CDN）＋ 重新部署即更新。
- 需要提供云环境 ID 与访问密钥；密钥不得写进前端页面。

## 3. 多人实时同步

- 目标：勾选状态跨设备可见。
- 方案：CloudBase 数据库/云函数，或任意 KV/文档数据库 + 轮询。
- 页面加一个 `trip_id` 与匿名 `member_id`，勾选写入远端；冲突时按最新时间合并。
- v1 的「导出/导入 JSON 合并」逻辑要保留为降级方案。

## 4. 内容来源增强

- 可选接入地图 POI 检索 API 校对地址与营业时间。
- 保持「不抓平台、只引用公开链接」的边界。
